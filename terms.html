서비스 이용 안내·약관

1. 사용 범위

프로그램은 본인이 관리 권한을 가진 채널과 업로드·사용 권한을 가진 콘텐츠에 사용합니다. 사용자는 Google 동의 화면에서 권한 범위를 확인하고, 공개할 영상과 공개 설정을 지정합니다. YouTube API Services를 사용하는 본 프로그램의 이용에는 YouTube 서비스 약관이 적용됩니다.

2. 자동 게시 동작

활성화된 게시대기 폴더에 넣은 완성 영상은 공개 게시 지시로 처리합니다. 파일명 앞 번호로 순서를 정하고, 비공개 업로드와 처리 완료 확인 뒤 한국 시간 오후 9시에 예약합니다. 이미 등록된 예약의 순서는 새 파일을 추가하는 것만으로 바뀌지 않습니다.

영상 전송에는 Mac 실행과 인터넷 연결이 필요합니다. 공개 예약이 YouTube에 정상 등록된 이후의 공개는 YouTube가 처리합니다. 네트워크, 인증 만료, 플랫폼 처리 지연이나 제한 등으로 예정된 업로드가 완료되지 않을 수 있으므로 게시 현황에서 결과를 확인합니다.

3. 중지와 삭제

자동 감시를 끄면 새 업로드와 예약 설정을 중지합니다. 이미 시작된 비공개 전송은 종료 처리될 수 있으며, 이미 YouTube에 등록된 예약 공개는 그대로 유지됩니다. 기존 영상이나 예약을 취소하려면 YouTube Studio 또는 별도의 명시적인 관리 요청을 사용합니다. 게시대기 폴더에서 파일을 지우는 것만으로 YouTube 영상이 삭제되지는 않습니다.

4. 정보 확인

데이터 접근·보관·외부 전달·권한 철회 방법은 개인정보처리방침에 따릅니다. 프로그램을 사용하는 운영자는 설정과 결과를 직접 확인하며, 기능 또는 운영 조건이 바뀌면 이 안내를 갱신합니다.
