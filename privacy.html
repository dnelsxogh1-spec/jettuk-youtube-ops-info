개인정보처리방침

이 방침은 제뚝이 채널 소유자가 본인 계정으로 사용하는 개인용 로컬 프로그램과 이 공개 안내 사이트에 적용됩니다.

1. 접근하는 정보와 목적

Google OAuth 승인을 통해 채널 ID·이름, 소유 영상의 제목·설명·공개 상태·조회수·댓글 등 메타데이터, 채널 분석 지표에 접근합니다. 사용자가 지정한 영상·썸네일·자막과 공개 설정은 업로드 및 채널 관리에 사용합니다. OAuth 토큰은 Google API 요청과 인증 갱신에 사용합니다. Google 비밀번호는 수집하거나 저장하지 않습니다.

2. 정보가 저장되는 곳

OAuth 클라이언트 설정과 토큰은 운영자의 Mac에서 접근 권한을 제한한 파일로 저장합니다. 작업 큐·업로드 이력·예약 정보·분석 보고서·명시적 관리 작업 기록은 같은 Mac에 보관합니다. 영상 업로드 중에는 파일 지문을 확인한 임시 사본을 만들며, 정상적인 전송 종료 과정에서 임시 사본을 정리합니다.

3. 외부 서비스로 전달되는 정보

사용자가 업로드·수정·삭제를 지시하면 필요한 영상·메타데이터·인증정보를 Google의 공식 API로 전달합니다. Codex 또는 연결한 AI 도우미로 작업을 요청할 때에는 요청한 작업 결과나 분석 내용이 해당 대화 서비스에서 처리될 수 있습니다. 프로그램은 OAuth 비밀정보를 공개 페이지나 작업 로그에 출력하지 않도록 구성되어 있습니다.

이 안내 사이트는 GitHub Pages에 호스팅됩니다. 사이트 자체에는 방문자 입력 폼, 광고, 별도의 추적 분석 도구가 없습니다. GitHub는 보안 목적으로 방문 IP 주소 등 서버 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침이 적용됩니다.

4. 이용 제한

Google 사용자 데이터는 사용자가 요청한 채널 운영과 분석 기능에 필요한 범위에서 이용합니다. 이 프로그램에는 사용자 데이터를 판매하거나 광고 타기팅에 제공하거나 AI 모델 학습용 데이터셋으로 수집하는 기능이 없습니다. Google API로 받은 정보의 이용 및 다른 앱으로의 전달은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

5. 보관과 삭제

소유자는 로컬 인증 파일·작업 기록·보고서와 원본 영상을 관리하거나 삭제할 수 있습니다. 중복 방지에 사용하는 작업 이력을 삭제하면 동일 영상이 다시 등록될 수 있으므로 자동 감시를 먼저 중지해야 합니다. 공개 안내 사이트에는 이러한 계정 데이터나 영상 파일을 저장하지 않습니다.

Google 계정 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 권한 철회만으로 Mac에 저장된 기존 보고서·영상이나 이미 YouTube에 등록한 영상이 자동 삭제되지는 않습니다. 로컬 기록 삭제는 해당 Mac에서, YouTube 영상·예약 삭제는 YouTube Studio에서 별도로 수행합니다.

6. 운영과 변경

사용자와 운영자는 제뚝이 채널 소유자 본인입니다. 별도의 외부 사용자 데이터 접수 서비스는 운영하지 않습니다. 데이터 조회·수정·삭제는 소유자의 로컬 관리 환경과 Google 계정 설정에서 수행합니다. 데이터 처리 방식이 바뀌면 이 문서의 내용과 날짜를 갱신합니다.
